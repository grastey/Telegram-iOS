# Private beta validation

The Android workflow compiles Java against the pinned official source tree. It does
not assemble or sign an APK, and does not need the Android signing key.

The iOS validation workflow checks the wire format, typechecks protocol storage,
and parses the modified Swift files. This does not replace a complete iOS build.

Device acceptance remains required: send a regular gift with a Unicode comment,
send a collectible, restart each client, and confirm that every new incoming gift
celebrates once without duplicating a card when the history is loaded again.
