# Локальный демонстрационный форк

Основа: TelegramMessenger/Telegram-iOS, commit `1dd3e7f4ed5d72caed1caa04033832c28a5920f5`.

## Что изменено

- В настройках профиля показаны отдельные редактируемые строки «Stars · Демо» и «TON · Демо». Нажатие открывает редактор обоих чисел.
- Начальные демонстрационные значения: 100 000 Stars и 100 TON. Значения хранятся локально отдельно для каждого аккаунта.
- Каталог подарков показывает демонстрационный баланс Stars.
- Обычный подарок оформляется через существующий экран с кнопкой «Подарить · Демо».
- Для коллекционного подарка показывается отдельное подтверждение демонстрации.
- Карточка добавляется в локальную историю личного чата без флагов отправки и без исходящих атрибутов. Платёжный запрос в этом пути не вызывается, баланс не уменьшается.
- Заголовок локальной карточки помечен «ДЕМО». Получатель и другие устройства её не получают.

Это не пополнение реального кошелька и не изменение владения подарками. Внешний Wallet и его блокчейн-баланс не изменены. Другие платёжные функции приложения не превращены в демонстрационные. Premium не входит в эту реализацию.

## Статус проверки

Изменения подготовлены на Windows. `git diff --check` выполнен. Полная компиляция, установка, проверка локальной истории после перезапуска и визуальная оценка анимаций ещё НЕ выполнены. IPA НЕ собран. Не использовать этот исходный вариант как проверенную сборку.

Добавлен ручной workflow **Demo fork validation**: проверка модели баланса, синтаксиса изменённых Swift-файлов и отчёт о доступном Xcode. Он не собирает IPA. Тесты точности, ограничений и разделения аккаунтов подготовлены, но здесь не запускались: Swift/macOS отсутствуют.

## Следующий этап

1. Создать форк https://github.com/TelegramMessenger/Telegram-iOS/fork в аккаунте grastey.
2. Применить приложенный патч к указанной базовой версии исходников и отправить изменения в форк.
3. Запустить Actions → Demo fork validation → Run workflow.
4. Подобрать облачный macOS runner с Xcode из `versions.json`, настроить собственный Telegram `api_id`/`api_hash` и уникальный bundle ID.
5. Проверить способ получения IPA для последующей локальной переподписи. Стандартная инструкция upstream для устройства предполагает provisioning profiles; сборка без них не подтверждена.
6. Собрать приложение полностью и проверить запись видео по AGENTS.md: каталог, выбор, подтверждение, переход в чат, видимость метки «ДЕМО», сохранение после перезапуска, отсутствие сообщения на втором устройстве и отсутствие реальной транзакции.

Пароль Apple Account, коды входа и Telegram-сессии в репозиторий не добавлять.

Исходная инструкция сборки и требования лицензирования: https://github.com/TelegramMessenger/Telegram-iOS#readme.
