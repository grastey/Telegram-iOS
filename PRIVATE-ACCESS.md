# GhostGram Private: личные коды

Каждому участнику администратор выдаёт собственный код, привязанный к числовому
Telegram ID. Один код подходит для Android и iPhone этого аккаунта. Код другого
участника не открывает доступ для своего Telegram ID.

При первом открытии приложение показывает экран приватки. После проверки кода
открывается обычная регистрация/авторизация Telegram. После входа проверяется,
что Telegram ID совпал с аккаунтом, для которого выдан код. Существующий вход
Telegram не сбрасывается. Новые пары вручную создавать не нужно: все включённые
участники обмениваются синтетическими подарками через общий relay.

Это ограничение официальной сборки вашего форка и доступа к вашему relay.
Сервер приватки не принимает SMS, коды Telegram, пароли и сессии Telegram, не
блокирует сам Telegram-аккаунт и не может запретить пользоваться другим клиентом.
Пользователи не получают историю чужих подарков: выдаются только события, где
их аккаунт — отправитель или получатель.

## Установка серверной части

На VPS уже используется /opt/ghostgram-sync и /var/lib/ghostgram-sync/relay.sqlite3.
Распаковать серверный архив в отдельный каталог и выполнить его deploy/update-relay.py
от root. Обновляется только служба ghostgram-sync; при ошибке проверки здоровья
прежний исходник восстанавливается. Таблица членства добавляется без удаления
ключей, событий и старых пар. Другой бот и его база не затрагиваются.

**Сначала обновить сервер, затем устанавливать новые клиенты:** старый сервер
не возвращает private_access и не даст открыть новую приватку. До создания
private member существующие ключи остаются бета-ключами.

## Выдать личный код

```bash
sudo python3 /opt/ghostgram-sync/relay.py --db /var/lib/ghostgram-sync/relay.sqlite3 member 8277161585 --label Alinka
```

Команда показывает код один раз. Срок по умолчанию — 365 дней; параметр
`--days 30` выдаст на 30 дней. Код сохраняется на сервере только как SHA-256.
Для другого человека заменить числовой ID на его настоящий Telegram ID.
Без доверенной проверки этого ID выдавать код не следует: публичной регистрации,
где клиент сам назначает себе чужой ID, в сервере нет.

На сервере после включения аккаунта его ранее выданные действующие бета-ключи
тоже получают членство. При желании отозвать все прежние ключи сначала выполнить
disable-member, затем member и раздать новый код.

## Отключить участника

```bash
sudo python3 /opt/ghostgram-sync/relay.py --db /var/lib/ghostgram-sync/relay.sqlite3 disable-member 8277161585
```

Отключается членство и отзываются все его ключи, включая второй телефон.
Старое разрешение пары не обходит отключение. Новый код выдаётся командой member.
Клиенты проверяют доступ при запуске и каждые 30 секунд; положительное разрешение
живёт только в памяти до 60 секунд. При отказе или потере связи экран доступа
закрывает интерфейс. При следующей попытке соединение можно проверить повторно.

## Что сохраняется на устройстве

Код сохраняется в Android Keystore/Keychain с привязкой к Telegram ID. Если защищённое
хранилище недоступно, проверенный код может действовать в памяти до закрытия
процесса. Открытым текстом на диск он не записывается. В общих настройках хранится
только ожидаемый числовой Telegram ID; положительное разрешение там не хранится.
Нельзя переносить доступ на другой аккаунт переключением аккаунтов или перезапуском.

## Что проверять перед выдачей

Неверный/отозванный/истёкший код, код от другого ID, отсутствие сети, переключение
аккаунта, выход/возвращение приложения, первый вход Telegram, обновление поверх
старой установки. На двух включённых аккаунтах отправить новый обычный подарок
и коллекционный подарок в обе стороны. Синхронизация выполняется при открытом
приложении; фоновые push-подарки этой версией не добавляются.

Готовая IPA требует личной переподписи владельцем, как предыдущая build 20.
Android APK подписывается прежним локальным сертификатом для установки обновлением.
Прежние анимации Фредди и девять чат-подарков из build 20 сохраняются.
